# Changelog

## 2.2 — 2026-10-30

* приветственный экран при первом запуске: оконный режим игры, установка плагина
  телеметрии, выбор фуры, кнопка «Начать»;
* YouTube: строка поиска и поле «ссылка на ролик» — сайт открывается прямо в окне
  кабины, `Ctrl+Alt+B` возвращает к медиасистеме (раньше был только один
  зашитый ролик);
* переключатели фур (DAF, Scania, Volvo, MAN, Mercedes, Renault, Iveco):
  позиция экрана запоминается отдельно для каждой;
* сервер больше не сыплет трейсбеками при закрытии страницы.

## 2.1 — 2026-10-30

* экран «Поездка»: скорость, передача, обороты, топливо, запас хода, AdBlue, круиз,
  одометр, износ узлов, расход, давление в контуре, трейлер, груз и маршрут,
  доход, дедлайн, прогресс рейса;
* свой плагин телеметрии на SCS Telemetry SDK 1.16 (`plugin/truckplay_telemetry.cpp`);
* плагин пишет JSON в файл вместо разделяемой памяти — прежний вариант падал
  на инициализации с `cannot map shared memory`;
* экран «Настройки»: размер S/M/L, положение, 4 темы, тумблеры «поверх всех окон»
  и «мышь по экрану», статус и установка плагина;
* установка/удаление плагина из интерфейса и батниками.

## 2.0 — 2026-10-30

* переход с окна Chrome (`--app`) на нативное окно приложения на WebView2;
* новый интерфейс в стиле CarPlay: боковая панель с часами, сетка приложений,
  «Сейчас играет», «Быстрый эфир»;
* радио из `live_streams.sii` и музыка из папки игры вместо хардкода;
* настройки сохраняются в `config.json` и применяются на лету.

## 1.0 — 2026-10-30

* первый рабочий вариант: окно с YouTube поверх игры, сквозная мышь,
  горячие клавиши, локальный сервер страницы.
